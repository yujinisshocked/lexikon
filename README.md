# Lexikon

An all-in-one life tracking mobile app with mini functions that makes life easier

---

## Description  <!-- What is this project? -->

**Lexikon** is an all-in-one life tracking app that aims to enhance life style
by replacing analog tools with one application 

### **Features**
- Note Taking
- Habit Tracking
- Scheduling
- To Do List
- Shopping List
- Budget Calculator
- Financial Tracker

---

## Platform

Android, IOS compatible. Written in flutter/dart.
